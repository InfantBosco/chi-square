# Chi-Square Machine Learning Statistics Project

A reproducible Python machine learning statistics project investigating demographic fairness and statistical independence using the American Community Survey (ACS) Income dataset from Fairlearn.

## Project Structure
```
chi_square_project/
├── data/
│   ├── raw/
│   └── processed/
├── notebooks/
├── src/
├── results/
├── figures/
└── report/
```

## Quick Start
1. Activate virtual environment:
   ```powershell
   .\chienv\Scripts\Activate.ps1
   ```
2. Download ACSIncome dataset:
   ```powershell
   python chi_square_project/src/download_dataset.py
   ```
