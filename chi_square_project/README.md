# Chi-Square Project Directory

This directory contains the pipeline, source code, data, notebooks, results, and reports for statistical and fairness analyses.

## Directory Layout
- `data/raw/`: Original, unmodified datasets (e.g., `acs_income_features.csv`, `acs_income_target.csv`).
- `data/processed/`: Cleaned, binned, and transformed data files for downstream modeling.
- `notebooks/`: Jupyter notebooks for exploratory data analysis and hypothesis testing.
- `src/`: Reusable Python modules and scripts.
- `results/`: Output summaries, hypothesis test statistics, and tables.
- `figures/`: Visualizations, plots, and figures.
- `report/`: Project reports, data dictionary, and documentation.
